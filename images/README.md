# Job photos


These are Heartwood’s own job photos, resized for the site. Originals are not stored here.

Each photo is a JPEG and a WebP at the widths in the file name (480, 800, and a larger size where the layout needs it). The widest file is 1600px. EXIF, including any GPS, is not kept in these files. They share one grade: corrected white balance, slightly lifted shadows, a little contrast and vibrance, mild noise reduction and sharpening, and a tighter crop. Horizons were already level, so nothing was rotated. The pages use `<picture>` so browsers that understand WebP get the smaller file, and the rest get JPEG.
